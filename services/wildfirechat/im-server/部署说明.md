# 部署说明
1. 下载最新版的im-server，https://github.com/wildfirechat/im-server.git
2. 修改原项目中的distribution/src/main/resources/wildfirechat.conf文件。
    2.1. server.ip改为服务器IP。
3. 修改原项目中的distribution/src/main/resources/c3p0-config.xml文件中的mysql配置。
```
<!--MySQL数据库地址-->
<property name="jdbcUrl">jdbc:mysql://192.168.1.80:3308/wfchat?useSSL=false&amp;serverTimezone=GMT%2B8&amp;allowPublicKeyRetrieval=true&amp;useUnicode=true&amp;characterEncoding=UTF-8</property>
<!--MySQL数据库用户名-->
<property name="user">yuyang</property>
<!--MySQL数据库密码-->
<property name="password">yuyang</property>
```
4. 编译im-server，在项目根目录下使用下面命令编译。
```
mvn clean package
```
3. 生成的软件包在```distribution/target/distribution-XX-bundle-tar.tar.gz```，把此软件包拷贝到docker目录下。

4. 将原项目中的distribution/src/main/resources文件夹下的配置文件拷贝到config目录中。
5. 将im-server包整个考到linux服务器中。
6. 服务器安装docker 和 docker-compose。
7. 使用下面的命令，将openjdk-8-jdk-alpine镜像安装到docker中。
```
docker load -i openjdk-8-jdk-alpine.tar
```
8. 执行下面的命令，启动im-server容器。
```
docker-compose up -d --build
```
9. 查看im-server容器日志，确认是否启动成功。
```
docker logs -f im-server
```
10. 在浏览器中输入地址 http://${ip}/api/version可以看到返回一个json文件。
